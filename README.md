# Cake_Bakery_Website

This repository contains the source code for a simple Cake Bakery Website. It includes an HTML page, a CSS stylesheet, and image assets to showcase the bakery's offerings. Additionally, it integrates Bootstrap for enhanced design and responsiveness.

## Project Structure

```
Cake Bakery Website/
├── image/           # Folder containing website images
├── index.html       # Main HTML file
├── style.css        # CSS file for custom styling
```

### Files

1. **index.html**
   - The main webpage structure is defined here, using HTML.
   - Links to Bootstrap for additional styling and responsiveness.
   - Contains placeholders for images, text content, and links styled by both `style.css` and Bootstrap.

2. **style.css**
   - Responsible for custom styling that complements Bootstrap.
   - Defines additional layout, colors, and typography for the bakery site.

3. **image/**
   - Holds the image assets used on the website (e.g., bakery items, banners, or icons).

## How It Works

- Open `index.html` in any modern web browser to view the bakery website.
- The `style.css` file ensures the website has a unique design, while Bootstrap provides responsive layouts.
- Images in the `image/` folder enhance the visual appeal.

## Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/cake-bakery-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd cake-bakery-website
   ```
3. Open `index.html` in your browser to view the website.

## Deployment

You can host this website using GitHub Pages:

1. Push the code to your GitHub repository.
2. Go to the repository settings.
3. Enable GitHub Pages under the "Pages" section.
4. Select the `main` branch as the source, and GitHub will host your website.
